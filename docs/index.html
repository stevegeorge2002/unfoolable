When AI says “done”, is it?

Unfoolable is a team of AI agents that cleans messy business data, and refuses to say “done” until an independent checker has redone part of the work and agrees.

Without a checker, our agents said “done” 9 times. 8 of those were wrong.
See one row go through it View the code on GitHub

Messy rows in. The checker’s beam verifies each one before it flips to clean.

The cleaning is easy. Knowing it’s right is the hard part.

Companies get spreadsheets from suppliers, banks and old systems, written every way imaginable: dates in five formats, prices like “1.234,50 EUR”, names as “SMITH, JOHN”, ids like “#3928”. An AI can tidy most of it in seconds. The danger is the few rows it gets wrong while confidently reporting success. In a file of 50,000 rows, nobody checks by hand, so silent mistakes become missed customers and wrong payments.

    Who does what, and why each one exists

    Doing the job

    🧹
    The workera.k.a. the Cleaner

    Writes its own checklist of what “done” means, then writes code that cleans the file.

    🔍
    The checkera.k.a. the Auditor

    Exists because the worker can’t be trusted to grade itself. It re-solves a few of the weirdest rows straight from the raw file, never looking at the worker’s answer, and compares.

    ⏱️
    The watchdogplain code, no AI

    Exists because AI gets stuck repeating itself. It spots loops and stalls, forces a new approach, and leaves a note for a human only when truly stuck.

    Getting better over time

    😈
    The sparring partnera.k.a. the Trickster

    Exists so the worker meets nasty cases in practice, not in production. It invents new messes like invisible characters and lookalike letters, and must prove each one can be undone so the game stays fair.

    🧑‍🏫
    The coach

    Reads the worker’s hidden mistakes after each round and suggests one lesson, with a prediction of how much it will help.

    ⚖️
    The testa.k.a. the Gate

    Exists because the coach is overconfident. Old and new versions sit the same fresh exam; a lesson is kept only if the score really rises.

    Honest limits

    Small samples9 hidden tasks per condition and one run each, so a few points either way is noise.

    The checker can be wrong tooIt is an AI that samples about 8 rows, so rare mistakes can still slip through, and it makes the team more cautious.

    Synthetic test dataBuilt on realistic generated business tables so the right answer is always known; not yet run on a real company’s files.
